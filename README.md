# 発表順ランダム選出ルーレット

プレゼンテーションや発表会で、発表者をランダムに1人ずつ選出するためのシンプルなWebアプリです。

## 概要

- 候補者を一覧で管理できる
- 1人ずつランダムに選出できる
- 決定済みの発表順を履歴として表示できる
- 音声エフェクト付きで演出を強められる
- 候補者名の編集ができる
- リセット機能付き

## 使い方

1. `code_artifact.html` をブラウザで開く
2. 「選出する！」ボタンを押す
3. ルーレット演出のあと、次の発表者が決定される
4. 必要に応じて「名前を編集」から候補者を変更できる
5. 「リセット」で最初からやり直せる

## 主な特徴

### 候補者の編集
- 画面上の「名前を編集」ボタンから候補者リストを変更可能
- 1行ごとに1人入力
- 空行は自動的に除外される

### 発表順の記録
- 決定された順番が一覧に残る
- どの人が何番目に発表したかを確認できる

### 演出
- ルーレット風の文字切り替え
- 決定時の効果音
- 紙吹雪アニメーション
- スポットライト風の勝者演出

- このアプリは静的なHTMLファイルです
- ローカルファイルとして直接開いても動作します
- ただし、ブラウザのセキュリティ制約により、ローカルサーバー経由で開く場合も動作します
